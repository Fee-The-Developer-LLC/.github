# Fee The Developer LLC

**Software and web development: websites, web apps, APIs, automation, and AI integrations for growing businesses.**

We design, build, and run production systems for small and growing businesses, from the first page of the website to the automations behind it.

## What we build
- **Websites and web apps:** fast, responsive, accessible sites with booking, payments, and client portals
- **APIs and integrations:** connecting the tools a business already runs on
- **Dashboards:** operations, reporting, and client-facing views
- **Automation and AI agents:** workflow automation, AI assistants, and MCP integrations with human approval built in

## How we work
Audit before building · security and data separation per client · tested, documented, and handed off clean.
